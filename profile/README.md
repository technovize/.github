# Technovize

**Technical books, and the code that comes with them.**

Technovize is an independent publisher of practical engineering books. Every
title is written by an engineer who built the thing first, and every title
ships with working companion code — not snippets, but complete programs you
can run, read and take apart.

We publish under our own ISBNs. The books are available as ebook and in print.

## Published

### The Signal Path — *Build the Tools That Watch Everything Else*
by KC Ramo · 313 pages · ISBN 978-90-8378-210-2

Observability from the ground up. The book follows Lens, a platform built from
scratch — from a single Go binary reading `/proc` to a federated,
petabyte-scale system. Every component is built from first principles, then
compared to the industry tool that does the same job.

## Companion code licence

The companion repositories use the **Companion Code License**: build with it,
learn from it, use it in your own work — just don't republish the book or the
code as your own. GitHub shows this as `NOASSERTION`, which is expected: it is
a custom licence, not a missing one.
